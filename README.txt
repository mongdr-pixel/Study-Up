STUDY UP PWA 배포 및 설치 안내

1. ZIP 압축을 풀면 index.html, app.js, manifest.webmanifest, sw.js, icons 폴더가 있습니다.
2. 이 파일 전체를 HTTPS를 지원하는 정적 웹호스팅에 업로드하세요.
   예: GitHub Pages, Netlify, Cloudflare Pages.
3. 업로드한 사이트 주소를 갤럭시의 Chrome으로 여세요.
4. Chrome 메뉴(⋮) > 앱 설치 또는 홈 화면에 추가를 선택하세요.
5. 설치 후 STUDY UP 아이콘으로 실행할 수 있습니다.

오프라인:
처음에는 인터넷이 연결된 상태에서 사이트를 한 번 열어 앱 파일을 캐시에 저장하세요.
그 후 시간표와 기존 학습 기록은 오프라인에서도 이용할 수 있습니다.
학습 데이터는 해당 기기의 Chrome 사이트 데이터(localStorage)에 저장됩니다.
브라우저 데이터 삭제, 앱 데이터 삭제, 기기 변경 전에는 앱의 목표·오답 메뉴에서 백업 파일을 내려받으세요.

주의:
file://로 index.html을 직접 열면 PWA 설치 및 서비스워커 오프라인 기능이 작동하지 않습니다.
HTTPS 주소가 필요합니다. 기록은 자동으로 서버에 동기화되지 않습니다.

[업데이트된 편집 기능]
- 시간표 탭에서 요일을 선택한 뒤 각 항목의 수정/삭제, 시간표 추가가 가능합니다. 기본 시간표 복원도 가능합니다.
- 체크 탭에서 학습 항목의 수정/삭제 및 새 항목 추가가 가능합니다.
- 변경 내용은 브라우저에 자동 저장되며 오프라인에서도 사용할 수 있습니다.
- 기존 버전에서 저장한 학습 기록은 같은 브라우저에 남아 있습니다. 앱을 업데이트한 뒤에도 기록이 보이지 않으면 기존에 사용한 브라우저와 동일한지 확인하세요.
